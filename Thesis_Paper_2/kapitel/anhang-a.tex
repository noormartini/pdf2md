\chapter{Appendix}

The appendix collects supporting material referenced in the main chapters.

\section{Implementation Code Snippets}

Selected code excerpts illustrating key components of the system. The full
implementation is available in the project repository.

\section{Complete Results Tables}

Full per-page metric scores for all four strategies across all 90 evaluated
pages are available in the \texttt{output/results.json} file generated by the
evaluation pipeline.

\section{Sample Documents and Outputs}

The three thesis documents used as the evaluation corpus are included as
\texttt{experiments/sample.json} configuration entries. Ground truth reference
files are located in the corresponding reference directories.

\section{Prompt Templates}

The five prompt variants used by the LLM integration layer are defined in
\texttt{strategies/prompts.py}. The variants are: \textit{default},
\textit{text}, \textit{formula}, \textit{table}, and \textit{diagram}.
